# Oracle Graph Learning Path

This page organizes Oracle Graph learning resources into a few routes. It links to the existing Oracle Database Insider overview and to examples in this repository; it does not reproduce the blog content.

## Choose a route

| If you want to... | Start here |
| --- | --- |
| Learn graph concepts and see an overview of Oracle Graph | [Oracle Graph Learning Path on Oracle Database Insider](https://blogs.oracle.com/database/oracle-graph-learning-path) |
| Create and query a property graph with Oracle AI Database 26ai | [26ai property graph getting started](property-graph/26ai/get-started/) |
| Work with PGQL property graphs on Oracle Database 19c | [19c property graph getting started](property-graph/19c/get-started/) |
| Explore RDF graphs and ontologies | [RDF examples](rdf/examples/) |
| Explore knowledge graphs and GraphRAG | [Knowledge graph demos](knowledge-graph/demo/) |

## Suggested sequence

### 1. Learn the graph fundamentals

Read the [Oracle Graph Learning Path article](https://blogs.oracle.com/database/oracle-graph-learning-path) for an introduction to property graphs and RDF graphs, graph tools, videos, and use cases.

### 2. Follow the property graph route for your database version

- **Oracle AI Database 26ai:** follow the [getting started guide](property-graph/26ai/get-started/), then explore the [26ai demos](property-graph/26ai/demos/).
- **Oracle Database 19c:** follow the [19c getting started guide](property-graph/19c/get-started/), then browse the [19c demos](property-graph/19c/demos/).

### 3. Explore RDF and knowledge graphs

- Try the [RDF examples](rdf/examples/), including the [university ontology](rdf/examples/university-ontology/).
- Continue with the [knowledge graph demos](knowledge-graph/demo/), including the [GraphRAG demo](knowledge-graph/demo/graph-rag/).

### 4. Keep exploring

- Browse [property graph algorithms](property-graph/algorithms/).
- Review the [repository README](README.md) for prerequisites, documentation, and additional examples.

## Before you begin

Requirements vary by example. Check the README in the relevant folder for database version, tools, and setup instructions. The repository's [prerequisites](README.md#prerequisites) section gives a general overview.
